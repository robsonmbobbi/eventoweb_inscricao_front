# Frontend de Inscrições

Este é o frontend do sistema de inscrições para eventos Espíritas, desenvolvido em **React** com **TypeScript**, utilizando **Vite**, **Tailwind CSS** e **Material UI (MUI)**. O projeto é moderno, responsivo e estruturado para facilitar o desenvolvimento e manutenção.

---

## Tecnologias Utilizadas

### React + TypeScript

React é uma biblioteca JavaScript para construção de interfaces de usuário.  
TypeScript adiciona tipagem estática, garantindo mais segurança e facilidade na manutenção do código.

**Principais benefícios:**

- Componentização e reuso de código.
- Tipagem forte com TypeScript.
- Fácil integração com bibliotecas modernas.

---

### Vite

Vite é uma ferramenta de build moderna que permite desenvolvimento rápido com hot-reload.

**Principais benefícios:**

- Inicialização de projeto extremamente rápida.
- Atualização instantânea ao salvar arquivos (HMR).
- Suporte nativo a TypeScript, JSX/TSX e módulos ES.

---

### Tailwind CSS

Tailwind CSS é um framework utilitário que permite escrever estilos diretamente nas classes do JSX, tornando o desenvolvimento mais rápido, consistente e leve.

**Principais benefícios:**

- Agiliza o desenvolvimento com classes prontas.
- Mantém consistência de cores, espaçamentos e fontes.
- Facilita a responsividade (`md:flex`, `lg:text-xl`).
- Gera CSS enxuto, removendo classes não usadas.

---

### Material UI (MUI)

MUI é uma biblioteca de componentes React prontos e estilizados que facilitam a criação de interfaces modernas.

**Principais benefícios:**

- Componentes prontos como Botões, Cards, Inputs, Icons.
- Fácil integração com Tailwind CSS.
- Layout responsivo com Grid e Box.
- Permite adicionar ícones e animações rapidamente.

---

## Como Executar o Projeto

```bash
# Instalar dependências
npm install

# Executar servidor de desenvolvimento
npm run dev

# Build para produção
npm run build

```
